# IntegraSign · Prototipo de interfaz

Prototipo en HTML, CSS y JavaScript de la plataforma IntegraSign (firma de documentos PDF por turnos). No tiene servidor: todos los datos son de ejemplo.

Abrir `index.html` para ver el mapa de pantallas.

- Con un correo que contenga «admin» (por ejemplo `admin@integrasign.ec`) el inicio de sesión pasa a la verificación con certificado .p12.
- Estados del trámite: `07-estado-tramite.html?estado=rechazado` (o `vencido`, `concluido`).
